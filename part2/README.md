## Entry Point

AbleSpace website and product navigation. The assessment asks to explore the workflow: AbleSpace -> Caseload -> Take Data.

## Navigation Steps

1. Open AbleSpace.
2. Navigate to Caseload.
3. Choose Take Data.
4. Observe the form or data-entry workflow.

## UX Observations

Use screenshots in `part2/screenshots/` to anchor observations. Focus on clarity, speed of completion, error prevention, and confidence after submission.

## Problems / Pain Points

- Document any unclear labels.
- Identify repeated inputs or unnecessary steps.
- Note any missing save/confirmation feedback.
- Note mobile or keyboard usability issues.

## Proposed Improvements

- Add stronger progress and submission feedback if the workflow feels uncertain.
- Improve field grouping and helper text where users might hesitate.
- Preserve drafts if the form is long.
- Make validation messages actionable and close to the field.

## Why Each Improvement Is Useful

Each improvement should reduce user uncertainty, prevent data-entry errors, or make repeated caseload work faster.
